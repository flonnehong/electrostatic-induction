# 정전기 유도 — 수업 자료

중학교 2학년 과학 **Ⅶ. 전기와 자기 — 1. 전기의 발생 — 가까이 하면 생기는 전기** 45분 수업용 웹페이지입니다.

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 생각 열기 | 5분 | 예상하기, 우리 반 예상 보기 |
| ② 실험 | 8분 | 빨대와 알루미늄 캔 관찰 |
| ③ 전자의 이동 모형 | 12분 | 대전체를 가까이 하며 전자의 이동 관찰 |
| ④ 모형 완성하기 | 10분 | 세 가지 경우의 전하 분포 나타내기 |
| ⑤ 확인 문제 | 6분 | 6문항, 사고력 |
| ⑥ 정리 | 4분 | 공기 청정기 필터와 미세 먼지 |

## 기록

학생의 반·번호와 활동 답은 구글 앱스스크립트를 거쳐 교사의 구글 시트에 저장됩니다. 이름은 받지 않으며, 학생 화면에는 반별 예상 인원수만 보입니다. 작성 중인 내용은 학생 기기의 브라우저에도 그날 동안 남습니다.

## 참고
