# 정전기 유도 — 수업 자료

중학교 2학년 과학 **Ⅶ. 전기와 자기 — 1. 전기의 발생 — 가까이 하면 생기는 전기** 45분 수업용 웹페이지입니다.

## 화면

| 파일 | 쓰임 |
|---|---|
| `index.html` | 학생 접속 신청 (반·번호) → 교사 수락을 기다림 |
| `lesson.html` | 수업 화면. 수락된 학생만 들어가고 단계가 하나씩 열림 (`lesson.html?demo=1`은 저장되지 않는 미리 보기) |
| `teacher.html` | 교사용. 수락·거절, 진행 상황, 자동 넘김 / 교사 컨트롤, 한 명만 다음 단계 열기 |

## 수업 단계

| 단계 | 시간 | 내용 | 마침 조건 |
|---|---|---|---|
| ① 생각 열기 | 5분 | 예상하기, 우리 반 예상 보기 | 예상 고르기 |
| ② 해 보기 | 8분 | 대전된 빨대와 알루미늄 캔 관찰 | 관찰 결과 고르기 |
| ③ 전자의 이동 모형 | 12분 | 대전체를 가까이 하며 전자의 이동 관찰 | (−), (+)대전체를 모두 가까이 하기 |
| ④ 모형 완성하기 | 10분 | 세 가지 경우의 전하 분포 나타내기 | 세 가지 모두 맞히기 (한 문제를 세 번 확인해도 인정) |
| ⑤ 확인 문제 | 6분 | 6문항, 사고력 | 6문항 풀기 |
| ⑥ 정리 | 4분 | 공기 청정기 필터와 미세 먼지 | 설명을 쓰고 활동 마치기 |

## 기록

학생의 반·번호와 활동 답은 구글 앱스스크립트를 거쳐 교사의 구글 시트에 저장됩니다. 이름은 받지 않으며, 교사가 수락한 기기만 저장할 수 있습니다. 학생 화면에는 반별 예상 인원수만 보입니다. 작성 중인 내용은 학생 기기의 브라우저에도 그날 동안 남고, 로그아웃하면 지워집니다. 교사 비밀번호는 이 저장소에 들어 있지 않습니다.
